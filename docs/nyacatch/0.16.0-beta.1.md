# 0.16.0-beta.1 音频提取 / 转换

原“音频转换”页升级为“音频提取 / 转换”，仍位于格式转换内。可拖入视频或音频，一次最多20个不同文件，查看编码、采样率、声道及原音轨预计输出后缀；选中耳机按钮可试听源文件，默认暂停，不自动播放。

输出选择“原音轨（自动格式）”时，直接复制第一条音轨，保留编码、采样率和声道，不重新编码。AAC/ALAC自动使用M4A，MP3、FLAC、Opus等使用兼容格式，PCM使用WAV。此时不展示码率和质量控件。提取不会提升原音质，也不把有损编码变成真正无损。

选择MP3、M4A、AAC、FLAC、WAV、OGG或Opus则明确重新编码，沿用原质量、码率和目录设置。无音轨、不可读文件或不支持直接复制的编码会在提交前提示；不支持复制时可选择转换格式。首版只处理第一条音轨，不自动导出所有语言音轨或保留字幕、封面、章节和元数据；源文件试听依照系统播放器的编码与默认音轨能力。

已完成下载的工具栏、截取记录的已选片段、拼接完成记录新增“提取音频”。发送前检查实际文件和音轨，加入现有音频草稿并保留其他类型草稿；已有音频草稿的格式与目录保留，空音频草稿使用原音轨模式。失效/无声/超限/正在提交/未知提交/草稿保存失败时阻止带入，不自动建单。

复用原任务表、2个处理槽、开始/停止/重试、草稿恢复和未知提交锁。原音轨任务归于音频记录，输出名称使用“源名称-audio”，同名自动另存并保留原件。旧草稿与原7种音频转换保持兼容，已有格式偏好不被自动重置。
