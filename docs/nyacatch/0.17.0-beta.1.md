# 0.17.0-beta.1 视频截帧 / GIF

侧栏新增“视频截帧 / GIF”。选择或拖入一个本地视频后显示大预览，默认暂停；添加文件不会自动创建任务。详细记录默认收在抽屉内，页面只显示最近一次导出的紧凑进度。

“截取图片”支持播放器定位、输入时间后定位，以及保存当前位置为 PNG、JPG 或 WebP。PNG 按原视频尺寸无损保存，JPG / WebP 可选质量；截帧位置受源视频的实际帧间隔影响。导出成功后保留视频，方便继续定位、连续保存多张图片。

“导出 GIF”支持入点、出点、I/O 快捷键和双滑块，最长30秒；可选5、10、15 fps，最长一边上限160、240、360、480或720像素，保持比例且只缩小。默认480像素、10 fps、循环播放。GIF不含声音，适合短片段；多颜色画面受GIF调色板限制。

播放器受Chromium编码支持限制；预览失败可以重试，GIF仍可手动填写时间范围。图片导出需要先定位到可用画面。不会读取系统剪贴板、浏览器Cookie或修改系统代理。

复用现有任务表、接口和两个处理槽；截帧/GIF独立分类，普通转换、截取和拼接记录继续分开。GIF分两次顺序处理：统计整个选区的调色板，再应用调色板，不在一个滤镜图中缓存整段视频。保留停止、重试、同名另存、原件保护和临时文件清理。

草稿独立保存。提交前先保存锁，确认建单与写盘成功后才启动；响应丢失或确认写盘失败时保留锁定，重启后须先检查记录再手动解锁，避免重复导出。

本版本为Windows本机开发beta，继续沿用本机自动交付。正式版GitHub Releases更新、其他设备与真实系统缩放不属于本轮验收范围。

Go全套、36项TS、类型/构建、真实目录包输出/异常恢复、240组界面/120组抽屉、受影响窄回归和本机自动交付已通过。已打开新版，原任务与下载保留，唯一活动回退0.16.0。详见项目验收报告`outputs/reports/0.17.0/0.17.0-beta.1视频截帧与GIF验收.md`。
