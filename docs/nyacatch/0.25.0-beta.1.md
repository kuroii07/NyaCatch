# 0.25.0-beta.1 · 设置中心维护

- 高级页统一显示网页缓存、兼容预览缓存和任务缩略图的占用，各自清理并可刷新。普通/隐私浏览均覆盖；网页缓存仅统计HTTP资源，不把它当成全部网站数据大小。
- 清网页缓存保留网站登录。清除网站Cookie、登录及站点存储为独立确认操作，不影响主界面会话、下载、任务、收藏或应用设置。清除后刷新网站重新登录。
- 兼容预览沿用2 GiB预算和活跃租约保护。缩略图仅清理合法已完成图片，保留使用中、生成中、未知文件及目录，拒绝缓存目录链接。首次完成状态在临时目录清理后发布。
- 代理及Docker草稿在同次运行中跨页面保留，未应用密钥不写入localStorage/sessionStorage；退出软件即丢弃。保存只提交修改字段，外部修改产生冲突时提醒核对或重置。
- 保存失败保留目标并可重试；回复丢失时读取实际配置确认。保存中防止重复提交。
- 配置日志仅记录已知字段名、未知字段数量和错误类型，后续日志不再写请求原值；不自动改写既有日志。
- 关于页突出喵拾版本，提供喵拾源码、问题反馈与发布页，保留MediaGo致谢。开发版仍由本机验收后交付，正式版GitHub自动更新尚未启用。

本次保持六分类和23个原设置字段，不增加设置备份恢复、搜索、缓存迁移或可调配额。
