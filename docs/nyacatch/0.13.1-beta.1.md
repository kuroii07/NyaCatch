# 0.13.1-beta.1 片段预览与入出点

片段截取选择本地文件后直接显示音视频播放器，默认暂停。可拖动定位，在需要的位置点击“设置入点”“设置出点”，或在预览区域使用I/O快捷键；时间框与双滑块同步，可跳转到入点/出点并预览选段。输入框内打字不会触发快捷标记。选中源文件后的上传区改为紧凑文件栏，短窗口保留左侧滚动与固定导出操作。

预览通过所属主窗口受控IPC和随机只读能力地址读取本地文件，支持Range，不上传或创建任务。换源、重试、离页和窗口销毁释放临时地址，保留原草稿、任务锁、格式输出和原文件保护。预览取决于Chromium支持的编码，失败时可重试或手填时间；未加入兼容转码代理。

本轮核心与数据格式不变。完整验证和本机交付记录见项目 `outputs/reports/0.13.1/`。测试保持媒体暂停，真实读取首帧及seek，播放控制通过拦截验证；实际连续播放与音画同步交由用户体验。
