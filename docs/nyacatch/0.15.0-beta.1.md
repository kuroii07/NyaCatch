# 0.15.0-beta.1 音视频拼接

新增独立的音视频拼接页，可一次添加2～20个本地视频或纯音频。列表支持拖动和上移/下移，允许同一文件重复出现；逐项预览并显示总时长。选择、预览和排序不会创建任务，点击开始拼接或仅加入队列后才提交。

视频输出MP4或MKV，以第一段尺寸为画布，保持比例缩小并居中补黑边，不放大小画面，统一为30fps/H.264。混合有声和无声视频时补静音，全无声视频保持无声。纯音频支持MP3、M4A、AAC、FLAC、WAV、OGG、Opus，统一48kHz立体声后导出。视频和纯音频不能混在同一批里。

输出名称不需要扩展名，可以使用源目录或自选目录。同名自动另存，保留原件和已有结果。拼接需要重新编码并使用临时磁盘空间，不能承诺画质提升或无损拼接；首版不含转场、交叉淡化、逐段调音、字幕或多音轨保留。预览沿用本地受控媒体会话，Chromium不支持的编码可能无法直接预览。非方形像素素材和特殊旋转角度未作完整覆盖验证。

拼接使用原转换执行器和最多2个任务执行槽，逐段处理后合成，避免20个源同时解码。任务独立归入拼接记录，详细操作位于默认关闭的抽屉，页面紧凑进度按本次任务ID读取。转换、截取和拼接记录互斥，旧任务不迁移。

草稿保留顺序和设置。先保存提交锁，再创建任务，确认结果保存成功后才清空输入并开始处理。提交结果不明时保留草稿与锁，重启后先核对拼接记录再显式解锁。保存确认失败时任务留在队列，不自动开始。

截取记录增加已完成输出复选框，可按勾选顺序发送到拼接。现有草稿需要确认追加，取消保留原草稿；文件失效、类型混合、超出20个或正在提交/结果不明时阻止带入，不自动创建任务。
