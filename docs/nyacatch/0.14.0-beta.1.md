# 0.14.0-beta.1 多片段截取

一个本地视频或音频现在可以保留最多20个片段，分别编辑名称和起止时间，再统一导出。点击片段时复用当前预览、暂停并定位到该段入点；列表独立滚动，预览保持主要空间。

每个片段生成独立文件，格式、质量和目录共用当前设置。输出名称可留空，自动沿用源文件与范围；填写名称时无需扩展名。同名文件自动避让，不覆盖原文件或已有结果。首版保持精确重编码，不含多段合并或无损快切。

截取页增加最近一次提交的紧凑进度，按已保存的任务ID读取，独立于记录页码。详细任务、停止、重试及打开位置仍在默认关闭的截取记录抽屉。

已完成的下载可通过单选工具栏、右键或单项菜单发送到片段截取。文件先检查有效音视频轨道，不自动创建任务；已有同一文件的片段保留，不同文件的未导出草稿需要确认后替换。正在提交或结果未知时阻止带入。

旧单片段草稿自动恢复成一个片段；旧任务、分类和数据表保持兼容。批量逐项确认并保存，已确认的片段从草稿移出，结果不确定的片段继续锁定，重启后需先查看记录再显式解锁。不要在未核对任务前重复提交。

仍使用原FFmpeg执行器和最多2个处理进程，保留源文件、输出校验、停止/重试和数据保护交付。Chromium不能预览的编码仍可手填时间导出，不自动生成预览代理。
