# 0.12.0-beta.1 合集识别与选集下载

支持B站BV链接的多分P、UP主公开视频合集和YouTube公开播放列表。明确的分P链接默认解析当前分P，也可通过“查看选集”展开。

在新建下载页粘贴合集链接并解析，即可进入批量工作台的“合集与选集”。支持50集分页、单项与Shift范围选择，选好后点击“解析所选”，检查保存目录、内容和各集画质，再明确加入队列或开始下载。一次最多处理200条视频链接，其他已有输入会保留，合集母链接会由所选集替换。

每集独立任务、输出路径与设置。B站多分P保存BV/CID，解析与重试时刷新对应p映射；原CID消失时明确失败。草稿保留分集身份、设置与未知提交锁，原单视频和单帖多资源流程保留。

本轮真实样例包含用户9P投稿的完整枚举、P2/P9实际视频音频下载与P2重试、24视频公开合集枚举，以及YouTube公开播放列表与分页。YouTube所测视频要求登录验证，未将该视频下载记为通过，也未自动读取浏览器Cookie。

首版不包含B站旧av/b23短链的自动合集识别、UP主series列表、番剧季度、私人收藏夹、账号全量视频、直播和其他网站的通用合集展开。已有单视频解析能力不等同于这些入口均完成合集适配。普通多链接输入仍逐链接解析，合集使用上方选集入口。

本版本继续为本机未签名beta。交付及完整证据见项目 `outputs/reports/0.12.0/`。
