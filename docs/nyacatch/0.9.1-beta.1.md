# NyaCatch 0.9.1-beta.1

统一输入控件的聚焦边界，修复搜索框、素材地址栏、设置数字框等处的多层描边。原生控件在自身边界显示焦点，带图标/后缀的复合控件由外层承载，内部编辑框不再重复描边；Ant Design输入、密码、数字和选择控件同步适配，弹窗与独立素材窗口共用规则。

保留按钮、链接、复选框的键盘焦点，以及输入的错误/警告状态。主题、组件布局与业务行为保持现有约定。沿用0.9.0全部功能及平台支持边界，继续为未签名beta。

通过命令行、隔离Electron与CDP检查，不使用Computer Use或操作用户桌面，不播放测试媒体。源码、所有既有修改和用户数据受保护；构建通过后使用备份与退出后升级流程，不强杀当前程序、不提交/推送/发布。实际验收与升级结果见项目父目录outputs/reports/0.9.1。
