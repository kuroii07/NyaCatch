# 0.22.0-beta.1 · 视频封装

新增独立“视频封装”页，提供无损换封装与视频/外部音频合并两种方式。复用原FFmpeg、任务表、两个处理槽及原文件保护，不引入额外依赖。

## 使用

换封装：选择或拖入最多20个不同视频，查看轨道与兼容性，选择MP4/MKV/MOV/TS和输出目录，再开始或加入列表。不会调整分辨率、帧率或画质；视频和音频直接复制，不自动转码。字幕不兼容时需换目标容器或使用其他处理功能，不会静默丢弃。

合并封装：选择一个视频和一个仅含一条音轨的纯音频文件，外部音频替换原视频的全部音轨。视频完整保留，音频较长时按视频结束收尾，较短时视频尾部无音频；不自动循环/拉伸/补音。提交前显示双方时长和处理方式。上方播放器仍预览原视频，替换效果在输出中生效。

默认在源目录另存，支持自选目录，同名排他另存。任务参数保存视频/外部音频的实际大小和修改时间，执行前复核，文件变化后需重新添加。草稿与不确定提交锁跨页面/重启保留，遇到未知结果需刷新并检查封装记录后显式解锁。封装任务只显示在封装记录中；不会混入转换、截取、拼接或压制记录。

## 范围

- 四种目标容器采用保守的逐轨编码允许列表。通过检查只代表编码组合可尝试，损坏文件/特殊编码参数/实际写入问题仍会明确报错；不宣称任意格式互转或所有播放器兼容。
- 首版只处理一条主视频轨道，保留兼容的全部音轨、字幕、章节与MKV附件。封面视频轨、其他主视频、未知数据轨暂不处理；TS不支持本轮的字幕/附件/章节组合。MP4/MOV生成的QuickTime章节数据轨通过章节表重建，不当作任意数据轨复制。
- 外部音频仅接受一条纯音频轨，不含封面/其他轨；带其他轨道的文件明确拒绝，需先提取纯音频。
- MP4常见H.264/H.265/AV1/MPEG-4视频及兼容AAC/MP3/AC3/EAC3/ALAC音频；MKV允许更多组合，MOV可保留部分PCM。实际表以服务端muxCodecAllowed为准，不自动改成AAC或转换字幕。
- 某些FLV/TS/编码可由FFmpeg封装但内置播放器无法预览，会显示准确提示；仍允许封装，输出可用本地播放器检查。本轮不自动生成播放代理。
- 更换容器不会提高画质，也通常不会大幅缩小文件；Windows/剪辑软件的播放或导入能力还取决于内部编码。
