# NyaCatch 0.26.0 · 界面与交互优化

当前源码版本为 `0.26.0-beta.5`。本页记录已完成本机验收的 beta 更新；公开安装版与免安装包仍为 [0.25.0](https://github.com/kuroii07/NyaCatch/releases/tag/v0.25.0)，不将源码同步视为正式版发布。

## beta.5：素材入口一致性

- 各媒体工具共用无素材入口：图标、虚线框、排版和选择按钮一致，保留各自文件类型与数量限制。
- 素材预览头补齐“从待添加列表移除”按钮；多文件只移除当前项，其他素材、设置与历史保留。
- 移除只清理待处理引用及相关预览，不删原文件；正在提交或结果待确认时继续锁定。

## beta.4：品牌与进度动效

- 工作台解析、任务下载、转换/截取/拼接/截帧/压制/封装及兼容预览共用 NcProgress；保留真实读数、不确定状态和屏幕阅读器语义，进度使用 transform 平滑推进。
- 进行中爪印轻动、暂停静止、完成对勾；状态真正变化时描边/轻弹或失败轻抖，历史列表不重复庆祝。
- 解析按钮三点加载且宽度固定，两张卡片显示主题骨架，解析结果错开入场；取消与换源仍由原请求保护。
- 确认创建任务后飞入一个不可交互猫盒，队列 +N 来自本次真实新增事件，徽标显示封顶 99；完成入口短暂点亮。
- 顶栏猫盒只在悬停时抖右耳。减少动画会即时停止循环、位移与视觉副本；未改业务数据、下载核心或素材播放行为。

## beta.3：切页性能修正

- 所有页面在原内容容器上仅做 200ms 透明度淡入。真实包追踪发现原 6px 位移动画会触发重复布局；保留稳定 main、Outlet、草稿和原生网页边界，移除这段位移。
- beta.2 已交付后发现该问题，因此以新版本修正，保留旧版包和验收证据。原定品牌动效顺延至 beta.4。

## beta.2

- 工作台输出模式、转换分类、平台视图和设置分类共用滑块指示器；快速切换会从当前位置续接，窗口/语言变化静态重定位。
- 侧栏共享选中块移动、图标轻摆、展开与标签淡入；素材页采用即时宽度切换和仅透明度淡入，保护原生网页边界。
- 页面切换在现有内容容器淡入，不为 Outlet 或业务列表增加重挂载 key。
- 最近任务、队列和完成列表增加入场、重排与删除淡出；删除副本不可交互，不延后原业务删除。
- Tooltip 悬停延迟统一为 300ms，消息与 Tooltip 只装饰内表面，保留组件库的弹层生命周期。
- 动态开启减少动画会清理尚未完成的位移、列表副本及过冲；保留静态选中和透明度反馈。
- beta.2 使用独立的验收和交付事务目录，保留 beta.1 历史记录。

## beta.1

- 统一动效时长、字号与控件圆角，辅助文字最小 12px，数字使用等宽数字排版。
- 按钮悬停轻微上浮、按下压缩与松开回弹；系统减少动画时保留静态反馈。
- 侧栏按下载、媒体工具、发现分组；合并与封装使用更易区分的图标。
- 不可用的输出选项采用透明底，预览占位跟随主题，深色设置面板增加层次。
- 创建任务后保留一条状态和查看队列入口，区分排队、启动与启动未确认。
- 五语代理文案说明现有开关的真实范围；输入框仍采用单层焦点边界。

beta.4 为本次进度条与品牌演出阶段；最终验收以本机报告为准。公开发行版本仍为 0.25.0；本机 beta 不自动发布到 GitHub。
