# 0.19.0-beta.1 目标体积与两遍编码

视频压制页新增“目标体积”，为每个完整视频指定MB大小，自动根据真实时长和AAC预算计算视频码率，以两遍编码分配码率。支持H.264/H.265与MP4/MKV，保留原尺寸/帧率或缩小、速度设置、20文件批量、试压、独立记录与原件保护。

目标体积模式使用AAC音频，无声视频仍保持无声；原样音轨复制继续在画质模式可选。试压使用整片对应的码率，显示片段真实大小与整片估算；简单内容可能明显小于目标，不会填充文件凑数。实际整片若超出目标则明确失败，不导出被截断的视频。

两遍共享同一任务与原有处理槽，显示连续进度和当前遍数；各任务独立保存临时统计文件，停止、失败和重试不会串用。过小/过大的目标在建单前提示，服务端不信任传入的时长。原画质预设、CRF、任务参数、旧草稿和未知提交锁保留。

范围与验收证据见项目根目录`outputs/reports/0.19.0/`。首版HDR/高位深、字幕和GPU支持边界保持不变。

Go全套、40项相关TS、真实目录包/异常恢复/三任务并发、80主界面与80抽屉及通用包回归通过。已保护数据交付并可见打开0.19.0，原21下载、8处理、7预览和8下载文件保留，三份数据库正常，唯一活动回退0.18.0。本轮无commit/push/公开发布。
