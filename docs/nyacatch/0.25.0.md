# NyaCatch · 喵拾 0.25.0

首个公开正式版，支持 Windows x64，基于 MediaGo 3.5.0。

## 下载与启动

从 [v0.25.0 发布页](https://github.com/kuroii07/NyaCatch/releases/tag/v0.25.0) 下载：

- `NyaCatch-0.25.0-windows-x64-setup.exe`：按用户安装，适合日常使用；数据在 `%APPDATA%/NyaCatch`，卸载保留配置和任务数据。
- `NyaCatch-0.25.0-windows-x64.zip`：完整解压到可写目录，运行 `NyaCatch.exe`；数据在程序旁 `data/`。不要只移动 EXE，旧任务仍使用原绝对文件路径。
- `SHA256SUMS.txt`：校验下载文件；`NyaCatch-0.25.0-third-party-sources.zip` 提供第三方源码与构建来源资料。

无需另装 Node.js、Go 或 FFmpeg。程序和安装器未签名，Windows可能显示未知发布者。仅发布 Windows x64，验收环境为 Windows 11 本机；未完成其他系统、跨机及全部 DPI 实测。

## 功能

链接与批量下载、已适配的 B 站多分 P/公开合集和 YouTube 播放列表、网页素材提取与手动收藏；本地支持格式转换、音频提取、片段截取、音视频拼接、截帧/GIF、CPU/NVIDIA 视频压制、目标体积两遍编码、字幕烧录、无损换封装以及视频/音频/字幕合并。

设置提供六主题、五种语言、缓存分类清理、网站登录数据独立确认清理、保存失败重试和诊断导出。兼容预览由用户显式生成低清副本，导出仍使用原文件。

## 更新与旧版数据

安装版延迟检查本仓库的正式 Release，默认不自动下载，可在设置开启自动下载；安装必须确认，软件退出不会自动安装。安装前检查所有活动/未知任务和预览占用，停止核心并备份配置和 SQLite，校验通过后才启动安装器。免安装版使用手动下载入口，开发内测继续本机交付。

旧免安装版升级前先退出程序并备份 `data/`，完整替换程序文件且保留该目录。改用安装版时，在“设置 → 高级 → 目录与诊断”显式选择旧版 `data`；停止下载与处理并释放预览后再导入。导入会备份安装版原配置与任务，媒体文件不会复制，原目录需继续保留。不自动接管其他 MediaGo 安装的数据。

素材网页仅保留捕获所需的两项提示接口；桌面文件、应用与更新能力仅对主界面开放，本机核心拒绝外部网页来源和非本机 Host。诊断导出不包含数据库、Cookie、Token、完整链接或本机路径；原始日志分享前仍需自行检查隐私。

## 验证与限制

已对正式包执行真实媒体输出、记录与重启保留、来源/IPC边界、设置布局及故障恢复验证，安装器执行隔离安装、旧 beta 数据导入、覆盖安装和卸载保留验证。更新服务的下载/校验失败、活动任务、预览占用、备份和安装启动失败恢复通过注入更新驱动验证；未宣称未来版本的完整在线跨版本安装已经实测。

收录解析规则不等于整站实测。登录、地区、平台风控和内容权限仍然适用；不绕过 DRM。NVIDIA 编码只验证本机样例，压制以8位SDR为范围。封装不提升画质，图片/视频尺寸保持比例且不放大。更多边界见[功能范围](support.md)。
