# 0.23.0-beta.1 · 音视频与字幕合并封装

视频封装的“合并封装”模式支持一个视频加音频、字幕或两者。音频和字幕均可选，但至少添加一项；无外部音频时保留原音轨，添加音频时替换原音轨。视频、音频始终直接复制，不重新压制。

## 使用

选择一个视频，切换合并封装。选择或拖入纯音频和/或SRT、ASS字幕，再选择兼容格式与输出目录，点击开始或入队。字幕成为可开关的独立软字幕轨，原有字幕保留并追加新轨；没有原字幕时新增轨设为默认。

推荐MKV：可保留SRT文本或ASS样式。MP4/MOV只支持新增SRT，必须明确勾选允许转成文本字幕（mov_text），部分样式会丢失。ASS需改选MKV；TS不接受本轮外部字幕。不兼容时明确阻止，不自动丢轨。原有字幕不会因为确认而转码。

字幕限制4 MiB，须有有效文本事件，接受UTF-8、带BOM的UTF-16与GB18030。选择后保存内容SHA256，提交和执行前复核；文件变化需重新选择确认。字幕使用原时间轴，不自动移时或裁剪，不烧录画面。ASS字体依赖播放器及本机字体，本轮不打包字体。

播放器仍预览原视频；新音频和字幕只在输出生效，请用支持软字幕的播放器查看最终文件。外部音频较长按视频结束收尾，较短保留完整视频；字幕超出视频时不自动修改时间，可能延长容器总时长，外音频路径按视频结束收尾时尾部字幕也可能受限。

原换封装、兼容检查、两处理槽、排他另存、独立记录及旧草稿保留。字幕参数和确认进入任务快照与未知提交锁，失败可按原ID重试。不包括字幕编辑、OCR或自动识别。
