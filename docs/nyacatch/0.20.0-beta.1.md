# 0.20.0-beta.1 字幕压制

视频压制页新增按视频独立绑定的SRT/ASS字幕设置，可通过选择或拖入添加、关闭、替换或移除。SRT支持字体、字号、颜色、描边和上中下位置；ASS保留原样式，两者均支持提前/延后。

新增“字幕效果（静帧）”，使用实际FFmpeg/libass渲染，可从当前播放位置、首句和手动输入时间查看。静帧明确标注，连续字幕效果使用带字幕短片试压检查；预览和编辑不创建任务，也不自动播放。

字幕可随原CRF或目标体积两遍编码一起输出。每个视频只使用自己绑定的字幕，两遍共用私有ASS文件；未绑定项不加字幕，其他轨道与章节范围沿用原有约定。字幕以SHA256快照保护，缺失或修改时拒绝继续，重新添加同路径文件会刷新检查和预览。

保留原件、同名保护、20文件批量、独立记录、草稿及未知提交锁。支持最多4 MiB的UTF-8、UTF-16 BOM和GB18030文本，字体使用本机已安装字体。具体范围与验收见项目根目录`outputs/reports/0.20.0/`。
