# NyaCatch 0.11.3-beta.1

- 素材提取首屏增加简短操作说明，收藏随窗口宽度排列，可用键盘打开和删除。
- 地址栏输入保留为草稿，访问后再切换页面；Esc恢复当前网址。设备按钮显示当前模式，提示切换目标。
- 浏览网页时始终显示捕获栏，不再因首次捕获或清空资源挤动网页。窄窗口上下排列，并保留拖动调整。
- 捕获列表增加总数、名称与链接搜索、资源类型筛选。默认突出资源名称、类型及来源域名，完整链接可展开查看。
- 清空捕获列表提供行内确认，不删除下载任务与文件。下载设置沿用原生弹窗，立即下载保留显式点击及提交中状态。

网页捕获的范围、代理和下载引擎保持现有行为；不能保证每个网站都能捕获。浏览与筛选不会自动创建下载任务。开发版沿用保护数据备份、正常退出、升级核验和打开新版流程。
