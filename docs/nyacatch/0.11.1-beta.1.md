# NyaCatch 0.11.1-beta.1

- 素材获取工具栏支持Tab聚焦、Enter和空格操作，按钮点击区域扩大到28px，显示完整标签和禁用状态。
- 下载工作台显示解析、目录、资源勾选及已提交等状态提示，禁用操作的原因支持五语。
- 转换设置独立滚动，开始转换和加入队列固定在设置区底部，当前禁用原因保持可见。转换记录的设置摘要字号增大。
- 动效遵循系统减少动画设置，加载状态保留文字反馈。
- 未变化的下载进度保留对象和快照，避免重复通知界面，保留重试清零与百分比规范化。
- 任务日志增加手动刷新和复制。关闭或切页会取消日志请求，迟到响应失效。

本机开发交付沿用保护数据备份、正常退出、升级核验和打开新版流程。
