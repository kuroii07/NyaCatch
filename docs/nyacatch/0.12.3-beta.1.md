# 0.12.3-beta.1 根据源视频限制分辨率

添加视频后自动读取尺寸，将高于源视频的分辨率置灰。1080P源可选择1080P及以下，4K源可选择4K及以下；保留“保持原始尺寸”，竖屏按相同长短边规则处理。

批量文件按其中最小的视频限制选项。未添加文件、读取中或尺寸未知时，仅可保持原尺寸。常用1080P方案同样受限；旧的过高偏好保留并提示改选，提交前重新检查，避免源文件被替换后继续按旧信息建单。

延续原比例、仅缩小和原件保护；尺寸为16:9参考值。音频/图片、8种视频输出、草稿和既有任务不变。读取尺寸不创建任务，不播放媒体，不持久化尺寸快照。

本机未签名beta，完整支持范围与验证见项目 `outputs/reports/0.12.3/`。
