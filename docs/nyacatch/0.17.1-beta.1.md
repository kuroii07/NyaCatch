# 0.17.1-beta.1 GIF帧率与尺寸

GIF帧率改为6、10、12、24帧/秒与“保持视频原帧率”。原帧率模式保留源帧序及时间间隔，不强制重采样为固定帧率；GIF的时间精度会使帧间隔取整，实际播放也受播放器影响。

尺寸改用适合GIF的像素档：240、320、480、640、720、960，按源比例显示输出宽高。例如16:9视频显示480 × 270，竖屏9:16显示270 × 480，方形显示480 × 480。保留“保持原视频尺寸”并显示源宽高；高于源尺寸的档位不可选，不放大、不裁切。此处不使用480P/720P/1080P/2K/4K/8K视频档位。

原任务的5/15fps和旧尺寸仍可重试。普通旧草稿的5→6、15→12，尺寸、路径、时间、目录和记录保留；未知提交锁内完整保留原参数，仍须先核对记录再解锁。

沿用30秒时长限制、两次顺序处理、原件/同名保护、独立记录及本机自动交付，不增加其他功能或线上平台验证声明。

同时修正本地媒体尺寸读取：识别视频旋转标签和显示矩阵，带90°/270°旋转信息的手机视频显示正确竖屏宽高，尺寸标签与实际导出保持一致。

Go全套、42项TS、真实CFR/分数/60fps/VFR帧数和时间戳、六档/原尺寸与旋转竖屏、240组界面/120组抽屉及通用包通过，已保护数据交付并打开新版，唯一活动回退0.17.0。详见`outputs/reports/0.17.1/0.17.1-beta.1GIF参数调整验收.md`。
