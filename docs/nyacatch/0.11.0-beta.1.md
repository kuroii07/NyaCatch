# NyaCatch 0.11.0-beta.1

## 下载后转换

- 已完成页可从单项菜单、右键菜单或多选工具栏发送文件到视频、音频、图片转换。
- 发送后先进入待处理列表，明确点击加入队列或开始转换后创建任务。每类最多20个文件，跳过重复与不可用文件。
- 提供 MP4 长边1920、MP3 192kbps、WebP 长边1920常用方案，保留用户选择的输出目录。
- 各类转换分别记住格式、质量、尺寸、码率和目录，切页或重启后恢复草稿。
- 恢复和提交前检查源文件。缺失文件显示提示，恢复文件后可重新检查。
- 提交状态随切页保留。响应不确定时，重启后继续锁定，刷新记录并明确确认后解除。

## 本机开发更新

- 程序处于托盘时，交付流程利用现有单实例入口恢复窗口，再正常退出、保护数据升级并打开新版。
- Windows 报告退出中的子进程错误时，短暂等待核心服务的实际退出事件。核心仍在运行时继续报告关闭失败。

## 验证边界

本轮使用本机真实下载和 FFmpeg 转换样例验证新流程，五语及明暗主题沿用现有组件。平台支持范围按既有公开样例证据记录。

本版保持 beta，Windows 10、其他实体设备及真实系统125%/150%缩放仍待验证。
