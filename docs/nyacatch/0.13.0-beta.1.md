# 0.13.0-beta.1 片段截取

侧栏增加“片段截取”。选择或拖入一个本地视频/音频，填写开始、结束时间，选择输出格式与目录，再点击“开始截取”或“仅加入列表”。时间支持秒数和时分秒，提供前10秒、前30秒、整段快捷设置；音频源禁用视频输出。

复用现有8种视频和7种音频格式、转换队列、进度、停止和重试。截取范围随任务保存；草稿独立恢复，响应未知时保留锁并要求检查记录，避免连续点击或跨页面重复建单。原文件和已有同名输出不覆盖。

首版为单文件单区间、重新编码精确截取，保持源尺寸。视频边界受帧、音频边界受采样及编码延迟影响；暂不提供播放器、无损快切、批量截取或多区间拼接。

Go全套、22项TypeScript测试、UI/Electron/preload类型、局部lint与生产构建通过。真实MP4/WAV截取、原件与重名保护、响应丢失重启及120项截取页布局通过；既有转换360项布局和通用目录包回归通过。完整证据见项目 `outputs/reports/0.13.0/`。
