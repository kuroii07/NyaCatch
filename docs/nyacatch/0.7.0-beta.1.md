# NyaCatch 0.7.0-beta.1

This update prevents anonymous metadata pages from launching operating-system applications through `bytedance:`, `snssdk1128:` and other non-HTTPS protocols. The production guard covers main-frame navigation, subframes, redirects and new-window requests. HTTP request filtering alone does not cover OS protocol dispatch.

Known Xiaohongshu single-post share links now resolve inside the existing anonymous browser helper. HTTP share links navigate through HTTPS, final navigation must identify a post, and new short-link image IDs include that post identity. Existing full-link image IDs and saved-task behavior are preserved. The same image queue, byte validation, non-overwrite protection and exact-resource retry remain in use.

Douyin image posts have an experimental adapter with finite resource counts, post-bound image IDs and a restricted image CDN. Public online note samples did not produce usable metadata in this environment. The platform catalog therefore continues to list video/audio/cover evidence, and all five locales identify the image adapter as experimental.

## Verification and limits

- Go test suite passed; 65 TypeScript unit tests passed.
- UI, Electron and preload type checks passed; the desktop production build passed.
- Real Electron fixtures blocked top-level app links, iframe app links, external-protocol redirects and new windows. Fixture protocols were handled inside an isolated session as a fallback so a failed test could not trigger an OS picker.
- The real Douyin short-link sample attempted `bytedance:` navigation during regression; those attempts were prevented.
- A 15-image Xiaohongshu share passed exact image selection, two image downloads, same-image retries and mixed batching with a Douyin video in the candidate package. Parsing itself created no tasks; media was never played.
- One public `.cn` short-link sample passed image download and same-image retry. A subsequent batch refresh of that sample failed at anonymous navigation; retry also failed while the independent video task succeeded. The precise cause is unconfirmed. This limitation is retained in the local evidence rather than converted into a universal support claim.
- Packaged platform evidence was checked in five languages and two widths, with local download, invalid-input isolation, uncertain-submit recovery, quit and reopen checks.

The commit hook had rewritten three UI array operations to ES2023 APIs while the existing UI target is ES2020. Compatible operations on fresh arrays were restored. Two style autofixes are disabled only for the UI; the existing compiler target and functional checks are retained.

The local 0.6.1 source checkpoint is `7d6693e7d23268aef881a932eef443e1a6045395`. No upstream code, lockfile or license was replaced. This remains an unsigned local beta. Windows 10, other devices and actual Windows 125%/150% scaling are untested; public distribution still requires license review.
