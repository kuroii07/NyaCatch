# 功能与支持边界

当前版本：0.23.0-beta.1，开发内测。已完成 Windows 11 本机验证，未发布公众安装包；其他操作系统未完成喵拾验收。

## 网站下载

全部支持网站页展示随包解析引擎的规则目录，规则数不同于网站数，也不同于实际下载通过数。网站可能因登录、地区、访问风控或上游变化而无法使用。

B站已适配BV多分P及UP主公开season合集，YouTube已适配公开播放列表枚举。频道、直播与其他未适配合集不能按已支持的选集能力承诺；YouTube部分下载可能要求登录。小红书、抖音等公开帖适配有样例验证与实验边界，不能视为全站支持，尤其不保证抖音图文可用。

素材浏览入口能打开官网，不代表它的全部资源可捕获或下载。网页自身的登录与权限限制仍然有效，不绕过DRM。

## 本地处理

- 转换与压制按实际轨道、编码和尺寸检查，不能保证任意格式互转；改变容器或放大尺寸不会提高画质。
- 视频压制目前限制8位SDR，NVIDIA能力通过实际编码检测。H.264/H.265 NVENC仅有本机显卡样例验证，不能扩大到全部驱动、HDR、高位深、AMD或Intel。
- 目标体积模式使用CPU两遍编码与AAC；原音轨提取始终选择首条音轨，尚未提供多音轨选择。
- 视频封装的MP4/MKV/MOV/TS采用保守编码允许列表；拒绝多个主视频、封面和未知数据轨等不支持组合。FFmpeg可处理的部分FLV/TS可能无法由内置播放器预览。
- 封装字幕是独立软字幕，压制字幕是烧录到画面。MKV可保留ASS样式文本，但实际字体依赖播放器与本机；MP4/MOV仅新增SRT经明确确认转文本字幕，可能失去样式。TS不接受本轮外部字幕。
- 原视频预览不显示合并后的新音频或新字幕，最终结果请使用兼容播放器查看。命令行解码或帧哈希检查不等同于连续播放和剪辑软件导入验收。

## 发布

GitHub当前只提供源码。开发期采用本机交付，正式版GitHub Releases自动更新仍在规划中。第三方依赖与源码许可证分别适用；公开安装包发布前还需核对分发条件与签名。
