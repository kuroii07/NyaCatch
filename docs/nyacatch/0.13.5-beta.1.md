# 0.13.5-beta.1 补齐完整目录网站入口

修复上一版多数条目显示“官网未收录”的问题。网站入口由106条增加至1718条，覆盖1754条规则的约98%；32条通用、嵌入及内部规则明确显示“无独立官网”，仅4条地址待确认。

地址根据同版本yt-dlp官方源码中的实际入口整理，原人工确认的官网继续优先。覆盖多个来源的规则先展开域名列表再打开，不随机跳到第一个网站；B站国际版、iQIYI国际版、QQ音乐和网页存档等保持独立。

保留原解析、搜索、分页、状态、主题及语言，不发起解析或创建下载任务。已有失败重试、等待期间防重复和键盘操作继续有效。网站地址收录不代表线上可访问性或下载能力已逐站实测。

数据在源码中保存，普通构建不联网；更新引擎时核对版本和精确规则，避免沿用旧目录。开发者可用`python -B scripts/generate-platform-websites.py --wheel <同版本官方源码wheel>`重建；来源下载地址与SHA256由`scripts/platform-website-source.json`固定，生成前核验，wheel只作读取且不安装到Python。当前已验证源缓存位于项目根`work/metadata/yt_dlp-2026.10.21-py3-none-any.whl`，不随应用打包。

验收与本机交付证据见项目`outputs/reports/0.13.5/`。
