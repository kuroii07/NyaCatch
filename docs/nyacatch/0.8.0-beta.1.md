# NyaCatch 0.8.0-beta.1

- 可直接粘贴分享文本，多链接转入批量草稿；保留签名参数和fragment，不自动创建任务。
- 批量草稿跨页面和重启保留链接、资源勾选和设置。恢复后重新解析，按稳定ID复原选择；不保存临时预览地址，提交未知状态继续锁定。
- 提交前按完整历史中的确切来源/已知单帖身份、资源与输出选项提示重复，可跳过、查看旧任务或再次添加。未知网站的不同链接形式不会擅自合并；不同图片、画质和音频格式分别处理。
- 素材整理使用共用折叠设置：按平台、平台/作者或日期分子目录，选择原标题、作者*标题、日期*标题命名，提供保存路径预览。默认不改变既有行为，仅影响新任务。

保留0.7.1支持平台页及既有下载、转换、六主题和五语。未扩展平台支持范围；继续为未签名beta，未提交/推送或公开发布。
