# NyaCatch 0.25.1 · 解析反馈优化

本机维护更新，公开发行版仍为 [0.25.0](https://github.com/kuroii07/NyaCatch/releases/tag/v0.25.0)。

- 单链接工作台显示实际解析阶段：解析链接、检查 X 帖子资源、尝试匿名备用解析。状态来自同一请求的后端响应。
- 双路线失败时，优先说明最终的网络、超时、限流、服务、访问限制或媒体验证原因；“错误详情”默认收起，展开可分别查看主解析和备用解析。
- 错误旁可一键重新解析，保留原始链接及查询参数；重试解析不会创建或启动下载任务。
- 可取消解析；更换链接、离开页面后忽略迟到结果，释放已收到的临时封面会话。重复点击不会并发提交同一解析。
- 五语及六主题沿用现有界面；批量页保留原有队列与单项重试，复用更准确的最终错误分类。
- 侧栏导航隐藏系统滚动条；小窗口仍可滚轮浏览，键盘聚焦会自动滚动到对应入口，底部设置与主题按钮保持可达。

不自动读取浏览器 Cookie，不更改系统或软件既有代理语义。匿名备用依赖第三方服务，不保证私密、已删除、风控内容或全部 X 链接可解析。新增反馈不会提高来源画质，也不会绕过平台权限。

本机仍采用旁置 `data/` 的目录包与保护数据交付；安装版/免安装版的差异及其他媒体功能见[0.25.0说明](0.25.0.md)。未签名，Windows 可能显示未知发布者。
