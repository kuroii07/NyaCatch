# 0.13.3-beta.1 平台解析入口

常用网站的“去解析”改为“解析链接”：先在平台页粘贴作品链接或分享文本，提交后带着链接进入解析工作台并自动解析，不再跳到空白页面。解析之后仍需明确选择入队或下载，取消或无效输入不发请求。

完整目录移除每条规则旁重复的入口，顶部保留统一“粘贴链接解析”。保留搜索、分页和失效状态，平台与规则的支持范围不变。多个链接可带到原批量草稿，保留原内容和未知提交保护；不会自动开始批量下载。原先合集全部使用高级入口的过时说明同步更正，已适配合集继续按原选集流程处理。

输入保留URL参数和片段，不自动读取剪贴板；导航意图用后清除，返回或刷新不重复解析。完整验证及本机交付见项目 `outputs/reports/0.13.3/`。
