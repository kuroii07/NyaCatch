# 0.24.0-beta.1 · 媒体兼容预览

本地播放器无法打开某些格式或编码组合时，可点击“生成兼容预览”。软件生成临时低清副本供预览、定位和标记入出点；所有截取、截帧、GIF、压制和封装输出继续读取原文件。

## 使用

- 普通可播文件沿用原生预览，不自动生成副本或创建处理任务。
- 原生预览失败后，点击“生成兼容预览”，查看等待/生成进度；可随时取消，换源或离开页面会释放本次请求。
- 生成成功后默认暂停，可拖动定位、标记入出点或截帧。界面明确标注兼容预览；源路径、分辨率和导出参数仍指向原文件。
- 缓存有效时自动复用，重启后仍可使用。需要释放空间时，点击播放器旁的“清理预览缓存”；正在被其他预览使用的文件会保留。

## 范围与资源

复用现有共享播放器，覆盖截取、截帧/GIF、压制、封装，以及使用该播放器的音频/拼接预览。视频副本使用H.264/AAC MP4、最长边不超过960像素，保持显示比例和旋转；纯音频使用AAC/M4A。预览选取首条有效视频和首条音轨，不烧录新增字幕，不替换输出音轨。

保留变帧率时间基准和原有音视频偏移。首次生成需要完整处理素材，长视频可能耗时较久；复用既有两个媒体处理槽，资源忙时等待，不新增处理记录或改变现有任务分类。

缓存位于软件数据目录的`preview-cache/`，按实际路径、大小、修改时间和处理配方版本复核；修改原文件后重新生成。缓存最多2 GiB、单个副本上限1 GiB、媒体最长8小时。文件大小和修改时间保持完全不变的原位篡改不属于完整内容哈希校验范围。

失败、取消或时间轴校验不通过时不发布副本；重启仅清理带本功能归属标记的中断生成目录。清理只处理已知缓存文件，不删除原件或无标记目录，不跟随缓存目录链接。

HDR兼容预览尚未支持，会明确提示使用HDR播放器查看原文件，避免错误颜色。损坏文件、特殊编码或超出缓存限制的内容可能生成失败；这不阻止原功能按各自的文件检查与参数条件导出。低清预览不能作为原始画质检查依据，原格式/播放器限制也不等于源文件无效。

开发阶段仍使用本机数据保护交付；本轮未发布GitHub Release。完整验证与交付证据见本机维护工作区的0.24.0报告。
