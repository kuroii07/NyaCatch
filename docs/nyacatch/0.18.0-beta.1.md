# 0.18.0-beta.1 视频压制

新增独立视频压制页。选择或拖入最多20个本地视频，先调参数，再明确加入列表或开始；复用已有两个处理槽，记录与普通转换、截取、拼接、截帧分开显示。

支持H.264/x264、H.265/x265与MP4/MKV，画质优先/均衡/体积优先三档、CRF及编码速度；尺寸保留原始或仅缩小，帧率保留原视频或使用常用档。音频可转AAC，或在兼容容器内原样复制第一条音轨。无声视频保留无声，原文件和同名已有输出受保护。

可以从指定位置试压5/10/20/30秒内的短片，切换源文件与结果比较，默认暂停。试压显示真实片段大小与整片估算；整片完成后显示真实体积和变化比例，压制并不保证一定更小。内置播放器不支持当前编码时会明确提示，可用本地播放器查看导出文件。

独立草稿、跨页忙碌状态及未知提交锁可恢复；丢响应或写盘失败后先核对记录再显式解锁，避免重复建单。服务端读取真实源文件大小、修改时间和视频时长，启动时拒绝已变化的源文件。记录刷新会重新核对输出是否存在，避免显示失效的体积数据。

首版仅处理8位SDR，明确拒绝HDR/高位深输入；不含目标体积、两遍编码、字幕烧录和硬件加速。软件使用本机开发自动交付，正式版GitHub Releases自动更新仍为后续计划。

Go全套、38项TS、真实目录包导出/异常恢复、40组主界面与40组抽屉及通用包回归通过。已正常退出0.17.1、保护数据升级并可见打开0.18.0；21条下载、7条处理、7条预览和8个下载文件保留，数据库正常，唯一活动回退0.17.1。验收与交付证据见项目根目录`outputs/reports/0.18.0/`。
