# 0.12.1-beta.1 素材提取首页与捕获抽屉

素材提取首页去掉大标题和说明，增加20个常用国内、海外网站入口。网站使用自身真实图标，随软件保存；点击在内置浏览器打开，不自动创建下载或收藏。

“我的收藏”继续支持手动添加、打开与删除；已知网站使用同一组本地图标，其他网站保留favicon，加载失败显示名称首字。

网页浏览时捕获资源默认收起，工具栏“资源”显示数量，点击后展开。宽窗口显示右侧抽屉，窄窗口显示下方抽屉；收起后网页恢复完整空间，捕获事件不会自动展开。保留搜索、类型筛选、完整链接参数、清空确认、下载设置与显式下载。关闭再打开抽屉会保留筛选与提交保护。

沿用六套主题、五种语言、键盘操作、独立素材窗口与合并流程。预置网站入口不表示已对这些网站的所有资源完成下载测试，原平台限制与合集支持范围继续有效。

本版本继续为本机未签名beta。完整验证与本机交付证据见项目 `outputs/reports/0.12.1/`。
