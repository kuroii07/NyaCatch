# 0.13.9-beta.1 文本右键编辑

统一补齐文本输入框的 Windows 原生右键菜单，可按当前输入状态使用撤销、重做、剪切、复制、粘贴、删除和全选。不再只依赖 Ctrl+V。

覆盖新建链接、批量文本、搜索、平台解析、设置、素材地址及独立素材窗口中的输入区域；移除素材地址栏与高级表单原来没有执行动作的复制/粘贴菜单。已有任务和收藏菜单保留，菜单文案跟随软件五种语言，禁用和只读状态沿用 Chromium 原生限制。

菜单通过 Electron 原生编辑命令操作当前输入控件，不增加剪贴板读取接口，不自动解析链接或开始下载。验收和保护数据交付记录见项目 outputs/reports/0.13.9/。
