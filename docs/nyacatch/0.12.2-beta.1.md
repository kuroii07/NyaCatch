# 0.12.2-beta.1 转换视频尺寸与输出格式

视频尺寸改为常见名称并标出参考像素：8K（7680×4320）、4K（3840×2160）、2K/1440P（2560×1440）、1080P（1920×1080）、720P（1280×720）、480P（854×480），保留原始尺寸选项。

常用视频方案显示MP4 · 1080P（1920×1080），转换记录摘要同步名称。标注尺寸以16:9为参考；仍按原比例缩小，不放大或裁切，竖屏按长短边对应。图片保留像素标注，旧视频边长设置不会丢失。

新增FLV、TS、AVI、M4V输出，视频共8种格式。FLV/TS/M4V使用H.264/AAC，M4V保存为含音频的MP4封装；AVI采用MPEG-4 Part 2/MP3。复用原队列、目录设置、草稿、重试、输出校验及原件保护。

本版本继续为本机未签名beta，完整支持范围与验证见项目 `outputs/reports/0.12.2/`。
