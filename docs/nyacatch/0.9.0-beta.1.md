# NyaCatch 0.9.0-beta.1

格式转换增加视频/图片长边上限、目标音频码率及自选输出目录。尺寸按比例缩小，不放大、不裁切；视频编码可能补齐边缘像素。无损格式不提供伪码率选项，OGG最高192 kbps、Opus最高256 kbps，其他有损格式最高320 kbps；实际码率取决于编码器和素材。

转换选项保存到任务，重新打开或重试仍使用创建时的设置。老记录没有options字段时沿用原行为。输出在目标目录中临时生成、检查后排他另存，保留输入和已有同名文件。

本版包含0.8.0分享文本识别、批量草稿、重复提示及素材整理全部改动。2026-11-07已在应用完全退出后备份并统一升级至outputs/current；保留0.7.1回退ZIP，原设置、7条开发预览任务和8个已有下载文件检查通过。升级与验收没有操作用户桌面，也未自动打开主窗口。

未提交/推送或公开发布；保持未签名beta。Windows 10、其他设备和真实系统125%/150%缩放未测。测试禁止播放媒体、不使用Computer Use。
