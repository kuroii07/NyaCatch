# 0.13.8-beta.1 素材浏览弹窗与快手兼容

修复素材提取中抖音反复唤起 Windows 应用选择弹窗的问题。应用协议保护覆盖主页面、子框架、重定向、新窗口及直接加载，普通、隐私和独立素材窗口沿用同一保护。

修复快手首页显示 result:2 JSON 的问题。桌面浏览采用当前 Chromium 主版本对应的标准 Chrome 标识，正确处理移动与桌面模式切换，保留原有网站入口、收藏及捕获抽屉。

本版不新增网站下载器，不读取用户 Cookie，不修改系统代理。网站本身的登录、验证码和访问限制仍适用；网页能打开不代表全部作品均可下载。验证与保护数据交付记录见项目 outputs/reports/0.13.8/。
