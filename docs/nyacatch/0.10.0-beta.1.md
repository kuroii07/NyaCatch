# 0.10.0-beta.1 · 自定义外观背景

- 设置 → 外观新增四款内置原创背景：晨光山丘、晴空云海、竹影湖面、暮色星空；默认仍为无背景。
- 可以上传一张本机 JPG、PNG、WebP 或 GIF，切换预设不会丢失已上传图片，可单独移除；GIF仅使用静态首帧。
- 背景不透明度可调0–100%，模糊可调0–30px，效果即时生效，关闭重开后保留。
- 图片只保存于本机外观偏好，不上传网络。单张限10MiB、解码限4000万像素；保存前最长边缩至1920并转为WebP，避免过大图片占满设置存储。
- 保留六套主题、侧栏反色、五种语言及主题选择；卡片维持可读背景。重置仅恢复背景不透明度与模糊，不清空主题或自定义图片。

验证：18项背景、设置迁移和版本测试，UI/Electron类型、局部lint/格式、生产构建通过。开发版与独立目录包各120组主题/语言/明暗/窗口布局通过，独立包上传、损坏/超大图片、写盘失败保护、正常退出重开持久化通过；基础目录包下载及任务重开通过。测试使用屏幕外隔离窗口，未使用Computer Use或播放媒体。

限制：本轮未重跑Go全套与线上各平台下载；不宣称所有用户图片、跨机器或所有系统缩放均已验证。内置素材浏览器的网页区域仍保持网站自身背景，不替换第三方网页。
